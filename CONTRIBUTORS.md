# Contributors

VoltCast grew out of a three-person battery-modeling collaboration and was later rebuilt as an open-source research prototype. This file records both stages without importing the privacy-sensitive competition history.

## Research foundation (February 2026)

| Public alias | GitHub identity | Evidence-backed contribution areas |
|---|---|---|
| Hspikes | [@Hspikes](https://github.com/Hspikes) | Simulation implementation, parameter and sensitivity studies, visualization, battery-aging research, and manuscript integration. |
| HYQ | Historical GitHub identity retained in commit metadata; the profile no longer resolved during the 2026-08-24 migration. | Battery and workload model construction, usage-scenario analysis, technical figures, and manuscript development. |
| LMY | [@Yoralen](https://github.com/Yoralen) | Model completion and review, manuscript compression, citation repair, and consistency checks. |

The archived working repository contains 118 authored commits: 53 by Hspikes, 39 by HYQ, and 26 by LMY. These counts include merge and editorial commits; they document sustained participation, not a ranking of intellectual value.

## Open-source reconstruction (August 2026)

Hspikes led the clean-room productization represented by the current Python package: privacy and licensing review, model refactoring, command-line interface, test suite, synthetic fixtures, bilingual documentation, and release engineering.

The rewritten code is not presented as line-for-line work by every research collaborator. Instead, the repository history attributes the research-foundation commit to all three collaborators and records the engineering reconstruction separately.

## Attribution and privacy

- Contributor names are the public aliases used in the original Git history.
- GitHub-safe `users.noreply.github.com` addresses are used for commit attribution; private historical email addresses are not republished.
- The original competition repository is preserved offline for provenance review but is not part of this public history.
